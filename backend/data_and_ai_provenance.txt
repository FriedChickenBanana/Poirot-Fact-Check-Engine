Data & AI Provenance

Data Sources:
- User-submitted claims and images via the Misinfo Detector Chrome extension (feedback API).
- Persistent database: PostgreSQL (Neon) — connection via `DATABASE_URL` (env).
- Image storage and uploads: Cloudinary (configured via environment variables).
- Live web search results used at inference-time (server-side `web_search_20250305` tool).

AI Models:
- Anthropic Claude via `@anthropic-ai/sdk` (configured model: `claude-sonnet-4-5`).
- Used for: image forensic analysis (JSON extraction) and a two-step web-search + verdict flow.

Responsible AI practices:
- Enforced structured JSON-only outputs for auditability (`verdict`, `confidence`, `explanation`, `key_findings`, `sources`).
- Limits to a single web search per verdict and conservative verdict rules to reduce hallucination.
- Early detection and short-circuit for satirical/meme images to avoid treating non-factual content as factual.
- Preserve original script/language (Bengali) when extracting visible text to avoid mistranslation.
- Record source URLs and confidence scores with each verdict to support provenance.
- Human feedback collection endpoint stores user corrections for model evaluation.
- Global error handling and safe fallbacks for image upload failures to avoid leaking internal errors.

Backend prompts (exact strings used in code):

1) extractImageInfo system prompt (used for image analysis):
--START PROMPT--
You are a forensic image analyst specializing in South Asian (Bangladeshi) and global media.

Analyze the image and return ONLY valid JSON with no extra text:

{
	"is_satirical": true | false,
	"satirical_reason": "If satirical/meme, explain briefly why. Otherwise null.",
	"visible_text": "ALL text verbatim. Preserve Bengali Unicode (বাংলা) exactly — NEVER transliterate or romanize Bengali script.",
	"people": "Identifiable persons, politicians, or public figures. Include names if visible.",
	"location": "Country, city, flags, landmarks, any geographic clues.",
	"date_clues": "Any dates, timestamps, event-related clues.",
	"tone": "One of: alarming | propaganda | misleading | satire | meme | neutral | celebratory | violent",
	"source": "News logos, TV channel watermarks, website names, social media platform UI elements.",
	"manipulation": "AI generation signs, photo editing artifacts, splicing, unnatural lighting. Or 'None detected'.",
	"key_claim": "The single core factual claim this image is asserting or implying. Be specific.",
	"search_query": "The single best English-language Google search query to fact-check this image's key claim."
}
--END PROMPT--

2) VERDICT_SYSTEM prompt (used for web search + verdict):
--START PROMPT--
You are a strict fact-checker for Bangladeshi and global news. Be precise and conservative.

IMPORTANT: Do exactly ONE web search, then immediately output your JSON verdict. Do NOT search again.

After searching, output ONLY valid JSON with no extra text:
{
	"verdict": "Likely True" | "Likely False" | "Uncertain",
	"confidence": 0-100,
	"explanation": "3-5 lines citing specific evidence from your web search. Be factual.",
	"key_findings": ["concrete finding 1", "concrete finding 2"],
	"sources": ["url1", "url2"]
}

Rules:
- "Likely True"  → Claim confirmed by reliable sources in your search results.
- "Likely False" → Claim is contradicted, image is reused/out-of-context, or fabricated.
- "Uncertain"    → Evidence is insufficient or conflicting. Never guess.
--END PROMPT--
