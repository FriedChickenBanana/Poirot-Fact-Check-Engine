Quick Start

curl -X POST https://poirot-api.onrender.com/api/v1/verify \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{"type": "text", "content": "Bangladesh won the 2025 Cricket World Cup"}'

  "verdict": "Likely False",
  "confidence": 92,
